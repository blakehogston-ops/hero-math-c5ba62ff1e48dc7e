# Dad voice script for Hero Math Academy

Blake: read each line in a warm, relaxed voice, as if Samuel is sitting next to you. Leave half a second of silence at the start and end.

**How to add them:** save each one as an MP3 named with its number (`01.mp3` … `25.mp3`) in the repo folder `audio/dad/`. Then list the numbers you recorded in `audio/dad/manifest.json`, for example `[1,5,6,12,20]`. Any line you skip is read by the iPad voice instead.
